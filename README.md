📌 Proje Açıklaması: static Anahtar Kelimesi ile Nesne Sayacının Doğru Kullanımı
Bu örnek projede, Java programlama dilinde static kavramı kullanılarak sınıf düzeyinde ortak veri yönetimi gösterilmektedir. Özellikle, kaç adet Memur nesnesi oluşturulduğunu doğru şekilde takip edebilmek için sınıfa ait bir sayaç (static değişken) kullanımı uygulanmıştır.

🎯 Amaç Nedir?
Kodun amacı:

Her memur nesnesi için isim ve maas gibi bilgileri saklamak,

BilgileriYazdir() metodu ile memur bilgilerini ekrana yazdırmak,

kanunuSoyle() adlı static metot ile tüm memurlar için geçerli bir yasa bilgisini göstermek,

Ve en önemlisi: Toplam kaç Memur nesnesi oluşturulduğunu doğru şekilde saymak ve göstermek.
